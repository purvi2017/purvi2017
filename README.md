## Featured Projects

<details open>
<summary><b>OmniBrain — Agentic RAG System for Document Intelligence</b></summary>

<br/>

An AI-powered **Agentic Retrieval-Augmented Generation (RAG)** system designed for intelligent document understanding and question answering. Built during the Axlero internship as a three-member team project, led by me as team leader.

| Attribute | Details |
|:--|:--|
| **Stack** | Python · FastAPI · Uvicorn · FAISS · LLMs |
| **Scale** | Multi-document knowledge base with semantic indexing |
| **Performance** | Vector similarity search via FAISS for fast context retrieval |
| **Security** | Server-side processing through a FastAPI backend |
| **Impact** | Turns unstructured documents into a queryable knowledge assistant |
| **Repository** | [github.com/purvi2017](https://github.com/purvi2017?tab=repositories) |

OmniBrain ingests documents, splits them into semantically meaningful chunks, embeds them and stores them in a FAISS vector index. An agentic layer decides how to retrieve and reason over relevant context before the LLM generates a grounded answer, reducing hallucination and keeping responses tied to the source material. The system is served as a FastAPI application.

</details>
